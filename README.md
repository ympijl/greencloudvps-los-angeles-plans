## 下单前要避开的四个坑

绿云的坑大多不在机器本身，而在购买流程里。

**1. 同一页面列出全部机房，容易点错。** 绿云的下单页把同一套餐的所有机房位置放在同一个页面里，纽约、洛杉矶、东京、香港挨着排（好在所有位置同价），而且同一个配置在不同机房的库存不同。手一抖选成别的机房，开通了才发现，换机房只能重新下单，官方不支持像搬瓦工那种机房互迁。

**2. 特价套餐不退款。** 前面已经说过，Budget KVM Sale 系列写了 No refund。月付的常规套餐相对安全，官方还宣传过 7 天退款保证和免费 DirectAdmin 面板赠送（促销帖口径），想先试试水的，从月付开始是更稳的做法。

**3. 完全无托管。** 绿云只负责硬件和网络正常运行时间，系统配置、软件问题、应用层故障都不在服务范围内，出问题得自己扛。控制面板方面，官方文档显示 KVM VPS 近年已引入 Virtfusion（Budget KVM Sale 购物车页也明确标注 Virtfusion），旧的知识库则以 SolusVM 为主——以你开通后收到的实际面板为准，重装系统会清空所有数据，操作前先备份。

**4. 库存波动大。** 特价套餐经常整个机房显示 0 Available，看到有货就别犹豫太久；另外部分机房的 IPv6 只给 /112 而非 /64（堪萨斯城是这样，洛杉矶目前是 /64），对 IPv6 数量有要求的先看清套餐页。

支付倒是省心：支付宝、微信支付、银联都支持，PayPal、信用卡、Bitcoin 也可以，国内用户付款没什么障碍。开通速度官方口径是付款后 15 分钟内，个别情况最长 2 小时。
